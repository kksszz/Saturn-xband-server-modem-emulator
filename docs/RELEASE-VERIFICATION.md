# リリースの検証

## v0.5.1 — 2026-10-13

サーバー／共通148件、Mednafenアダプター3件、SCI4件をRelease構成で再確認し、全件成功。サーバーを再ビルドした。今回の変更は[最適化検証記録](../integration/mednafen/LINK-OPTIMIZATION-VERIFICATION.md)にまとめる。Mednafen本体のSCI差分と現行ソースの逆適用検査も通過した。最終ユーザー試験の対象・設定・バイナリ識別と音声調整の位置づけは同記録を参照する。

配布ZIPはソース・差分・ガイド・サーバーを収録し、エミュレーター本体・個人データは含めない。既存のv0.5.0は更新せず、新しいv0.5.1として公開する。PS1/SSのMednafen本体統合は別作業であり、このZIPの検査は統合済みフルパッケージの検証を意味しない。

## 2026-10-12 差し替え版

利用者の依頼により、同じv0.5.0のWindows x64 ZIP・SHA256SUMS・対応ソースタグを最新内容へ更新する。初回公開版とはZIPのハッシュと対応コミットが異なる。manifestの`package_revision=2026-10-12`と`source_commit`で識別する。旧ZIP・SHA256SUMS・旧タグ情報は手元に保管し、v0.4.0以前と利用中の保存データは変更しない。

更新内容はサービスendpoint名称整理、peer endpointによる対戦先指定、Subscriberの固定番号制約解除、全10タイトルのDISC根拠と標準表示名、仕様書・両組み込みガイド・READMEである。3台以上のモデムセッションは開発検討事項であり、未実装。対戦ケーブルの動作コードは今回変更していない。詳細は[endpoint名称の検証](SERVICE-ENDPOINT-RENAME-VERIFICATION.md)と[対戦先・ゲーム定義の検証](PEER-ROUTING-CATALOG-VERIFICATION.md)を参照する。

Windows x64、Visual Studio 2022、Release構成で再検証した。

配布候補と最終ZIPの動作コード・統合差分・サーバーEXEは同一とし、最終ZIPでは検証記録と梱包検査を更新して全ハッシュを再生成・検査する。依存JSONライブラリは既存キャッシュを使用した。新規PCでの初回ダウンロード試験ではない。今回の実ゲーム手動試験とMednafen本体の再ビルドは実施していない。

長いリポジトリ内の全試験ビルドではMSBuild FileTrackerのパス長エラーが発生したため、サーバーEXEは個別ターゲットでビルドし、全回帰試験とZIP展開後ビルドは短い独立パスで確認した。

公開時はGitHub上のZIP・SHA256SUMSのサイズ／SHA-256と対応タグのコミットを確認し、旧v0.4.0の配布状態を保持する。

## 2026-10-11 初回公開時の記録

2026-10-11（JST）。公開開発版の配布検証記録です。公開準備では文書と配布区分のみ更新し、
ローカルで検証済みの実装・統合差分・サーバーバイナリーは変更していません。

- Mednafen XBAND：VF Remixの対戦成立・終了後切断・再対戦、メール送受信、
  通常各3度数（100→97）、勝者+1／敗者0、再接続で二重計上なし、メール課金／無料受信。
- 通信ログ閲覧機能の確認完了が報告されました。
- Mednafen SCI：Daytona USA Circuit Editionの動作確認完了が報告されました。

  再対戦・リセット・状態復元の全組合せまでを確認済みとはしません。

### 自動試験と配布検査

- サーバー／共通部品の最新Windows x64 ReleaseビルドとCTest 60/60が成功しました。
- YMIR基準ソースと配布差分の逆適用チェック、最新XBAND部品を参照する本体Releaseビルド、
  標準14件＋検証コピーだけに追加した通信回帰7件のCTest 21/21が成功しました。

  展開したMednafen XBANDアダプターのRelease試験3/3、シリアル共通部品の独立試験3/3も成功しました。

### 残る制限

同一PCの独立2プロセスでの結果です。異種エミュレーター間・別PC間・実カード・
全タイトル・完全な物理通信再現は未検証です。Mednafen SCIの同期中は片側停止が相手を待たせます。
ハードリセット／状態ロード後は左右を再起動します。SMPCソフトリセットNMIの切断は未結線です。
SCI共通試験は以前に負荷下で一度失敗し、後の反復で再現しなかった事象を未解決として保持します。
接続回復後の表示へ古いエラーが付く場合も、現行の実験版制限として保持します。

初回公開時のパッケージ作成では、既存リリース、稼働ゲーム／サーバー、個人保存データは変更していません。2026-10-12のv0.5.0差し替えは上の更新記録に区別して記載します。
