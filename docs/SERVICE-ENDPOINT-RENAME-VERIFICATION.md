# サービスendpoint名称整理の検証

更新注記（2026-10-12）：以下は差し替え前の名称整理時の検証記録です。検証済みの変更はv0.5.0差し替え版にも収録します。最新の配布検証は[リリース検証記録](RELEASE-VERIFICATION.md)を参照してください。

2026-10-11。v0.5.0公開後の現行ソースの検証記録です。公開済みv0.5.0のタグ・ZIPの再検証記録ではありません。

## 変更範囲

- サーバーとYMIR／Mednafenアダプターのサービス識別子を`service-0`／`service-1`へ変更。
- 更新サーバーは旧`pb3-0`／`pb3-1`を同じ接続枠の別名として受け付け、モニターは新名で1端末1行を表示。
- 応答のwire endpointはクライアントが使用した名前を保持。`peer-*`／`call-*`、ポート、キー、wire v2は変更なし。
- メールの端末照合は両表記に対応。旧スナップショットの表記、本文、ID、送信元記録を保持。
- 新アダプターから旧サーバーへの接続は対象外。公開済みタグ・ZIP、利用中プロファイル・保存データは変更なし。

## 自動検証結果

Windows x64、Visual Studio 2022、Release構成で成功しました。

| 対象 | 結果 | 範囲 |
| --- | --- | --- |
| サーバー／共通部品 | 147/147 | `XBAND_WITH_JSON=ON`。既存サーバー試験とJSON／TCP試験、新しい互換試験を含む |
| YMIR統合 | 21/21 | 固定基準ソースで本体を再ビルド。標準14件＋通信回帰7件 |
| Mednafenアダプター | 3/3 | バス・サターンメディアカード・コマンド／対戦制御ランタイム |

主な互換試験：

- `xband.handshake_aliases`：旧名・新名の接続枠排他、切断後再利用、別端末の独立性、キー検査、別名衝突・不正設定拒否。
- `xband.host_service_alias`：実loopback TCPで旧名・新名のhello／open／data／advance、同一ペイロードの往復、正規名のモニター表示、切断後OFF。
- `xband.mail_profile_names`／`xband.mail_profile_mailbox`：旧記録への新名照合、端末・epoch・プレイヤー隔離、重複別名・名前競合拒否、保留メールと保持IDの照合。
- `xband.mail_profile_restart_snapshot`：旧表記のスナップショット復元、新名での検索、バイト単位で同一の再エンコード。本文・custody ID変更なし。

これらは隔離した自動試験です。今回の名称整理後の実ゲーム手動試験や別PC間試験を実施したという意味ではありません。Mednafen本体の再ビルドは今回行っておらず、変更したアダプターのビルドと上記試験を確認しました。

採用仕様は[サーバー／モデム仕様](SERVER-MODEM-SPEC.md#サービスendpointの名称と旧版互換)、公開済み配布物の検証は[リリース検証記録](RELEASE-VERIFICATION.md)を参照してください。
