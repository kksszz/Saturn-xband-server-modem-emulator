# 通信統合差分の検証記録

## v0.4.0（2026-10-11）

基準コミットと統合差分はv0.3.1と同じです。外部XBANDモデム部品をv0.4.0へ更新します。基準ソースの既存検証コピーに対して配布差分の逆適用チェックが成功し、最新部品を参照したWindows x64 ReleaseのYmir全体ビルドが成功しました。個別タイトルHotfixや使用中のゲームプロセスには変更を加えていません。

- 標準14件＋通信回帰7件のCTest21件を再実行。電話線・リセット試験は現在のカード管理通信、通信中のカード交換、OFF→ON、度数の保持を含みます。
- サーバー／モデム部品側はReleaseでビルドし、CTest59件を再実行。カード管理UI、各端末の状態報告、マッチ成立前のカード検査、メール課金・キュー復旧・ID衝突防止、宛先解決、共通待ち時間、対戦紹介のタイトル表記を含みます。
- 新しいカードは独立した合成ファイルとして作成し、旧カードを上書きしません。入力範囲0～32767、50／100プリセット、「OK」で自動保存・適用するUIを検査しました。32767のROM表示、送信による32766への消費、通信中の交換は利用者のゲーム画面操作でも確認されました。

既存依存ライブラリキャッシュを使った検証であり、新規PCでの依存取得、全タイトル、実カード、別PC間の実プレイを保証しません。ROM固定メッセージ全体の到達条件の解析は継続中です。配布にYmir本体、ROM、カード試験データ、個人の履歴・台帳は含めません。
