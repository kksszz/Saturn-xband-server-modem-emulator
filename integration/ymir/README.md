# YMIRソースへの通信統合差分

YMIR本体・EXEではなく、利用者が取得したソースへ適用する差分です。

まずは同一PC上での試験を対象とします。XBANDは同一PC上のサーバーと2つのYMIR、対戦ケーブルは同一PC上の2つのYMIRの直接接続を基準に確認しています。LAN設定の実装は、別PC間の動作確認済みを意味しません。

- 基準：`9a237ea6642912ae0833f691809aa47dc27f908d`（2026-10-07に取得したソース）
- `ymir-9a237ea-serial-xband.patch`：Serial Port画面、対戦ケーブル、SCI・DMA・割り込み、実行予算と同期、XBANDモデム接続、カード設定UI、保存・リセット境界、MSVC型互換性の差分。
- `apply-integration.ps1`：基準コミットと未変更状態を確認して差分を適用。
- `build-ymir.ps1`：外部モデム部品を参照して利用者の環境でビルド。
- `LICENSE-GPL-3.0.txt`：YMIR上流のライセンス本文。差分に含まれる上流由来部分の表示を保持するために収録。

手順は[YMIR専用マニュアル](../../docs/YMIR-INTEGRATION-MANUAL.md)の3.4章を参照してください。手動による移植の説明は10章です。

v0.4.0は同じ基準ソースと統合差分を使い、外部モデム部品を更新します。既にv0.3.1の差分を適用済みなら、差分を重ねて適用せず、`Ymir_XBAND_COMPONENTS_DIR`をv0.4.0の部品へ向けて再ビルドしてください。未導入の場合は従来通り付属スクリプトで基準ソースに適用します。新しいカード統合UI・状態報告・差し替えには、サーバーとモデム部品の両方を更新してください。詳細と未確認範囲は[検証記録](VERIFICATION.md)を参照してください。

旧テスト番号のプリセットと、環境変数による試験用の自動接続・カード自動挿入は含みません。既存のオプトイン観測コードは通常無効です。新たなタイトル別料金分岐、ゲームデータ、ユーザープロファイル、実カード、通信ログは含めていません。作業環境の追加のタイトル別診断とCDブロック変更もこの差分には取り込んでいません。

この差分は特定の基準ソース向けであり、現在のnightlyに無条件で適用するものではありません。対戦ケーブルはYMIR同士の直接TCP接続で、XBANDサーバーを使用しません。XBANDモデムとは同時に使用できません。

YMIR全体のソースやビルド済みアプリをこのリポジトリへ追加したものではありません。新規PCでの依存ライブラリ取得や全ゲームの動作を保証しません。統合後の再配布を行う場合には、上流を含む各構成要素のライセンスを別途確認してください。
